VoidOS APT repository

Add this repo once, then voidwm installs and upgrades like any other package.

1. Add the signing key

curl -fsSL https://VoltacceptsProjects.github.io/VoidOS-Repo/key.asc \
  | sudo gpg --dearmor -o /usr/share/keyrings/voidos.gpg

2. Add the repo

echo "deb [signed-by=/usr/share/keyrings/voidos.gpg] \
https://VoltacceptsProjects.github.io/VoidOS-Repo stable main" \
  | sudo tee /etc/apt/sources.list.d/voidos.list

3. Install

sudo apt update
sudo apt install voidwm

Future releases show up automatically with sudo apt upgrade.
